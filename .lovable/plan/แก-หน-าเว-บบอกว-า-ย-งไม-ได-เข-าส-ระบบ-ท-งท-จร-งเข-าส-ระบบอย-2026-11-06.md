# แก้: หน้าเว็บบอกว่า "ยังไม่ได้เข้าสู่ระบบ" ทั้งที่จริงเข้าสู่ระบบอยู่

## สาเหตุ (ตรวจแล้ว)
ตอนนี้ในหน้าตัวอย่างคุณยังเข้าสู่ระบบด้วยบัญชี **ผู้ดูแลระบบ (admin)** อยู่ ระบบเลยยอมให้เปิดข้อสอบ ซึ่งถูกต้องตามกฎ
แต่บัญชี admin ไม่มีข้อมูลโปรไฟล์ (ชื่อ/โรงเรียน) แถบเมนูหาโปรไฟล์ไม่เจอ จึงแสดงปุ่ม "เข้าสู่ระบบ" ทำให้ดูเหมือนยังไม่ได้เข้าสู่ระบบ
คนที่ไม่ได้เข้าสู่ระบบจริงยังเปิดข้อสอบไม่ได้ ผมทดสอบแล้วว่าถูกพาไปหน้าเข้าสู่ระบบทุกครั้ง

## สิ่งที่จะแก้
1. แถบเมนูรู้จักบัญชี admin: แสดงป้าย "ผู้ดูแลระบบ" พร้อมลิงก์ไปหน้า /admin และปุ่มออกจากระบบ แทนปุ่ม "เข้าสู่ระบบ"
2. ถ้ามีบัญชีที่เข้าสู่ระบบได้แต่ไม่มีโปรไฟล์และไม่ใช่ admin (บัญชีผิดปกติ) ให้ออกจากระบบอัตโนมัติ ปุ่มในเมนูจะได้ตรงกับสิทธิ์จริงเสมอ
3. ลบผลสอบที่ค้างในเครื่องเฉพาะตอนไม่มีการเข้าสู่ระบบจริงเท่านั้น ไม่ลบตอน admin เข้าใช้งาน

## รายละเอียดทางเทคนิค
- `fetchAccount` (src/lib/session.ts): ถ้าไม่มี profile แต่ `user_roles` มี admin ให้คืนบัญชี role "admin" (ชื่อ "ผู้ดูแลระบบ"); ถ้าไม่มีทั้งคู่ให้ `signOut()` แล้วคืน null
- เพิ่ม "admin" ในชนิด Role ที่ใช้ในเมนู และปรับ `AccountChip` ให้แสดงลิงก์ /admin
- ตรวจหน้าที่ใช้ `acc.role` (teacher/dashboard) ว่ารองรับค่า admin โดยไม่พัง
- ทดสอบด้วย Playwright: เข้าแบบ admin แล้วเมนูต้องแสดง "ผู้ดูแลระบบ" และเข้าแบบไม่ได้เข้าสู่ระบบต้องถูกพาไปหน้า /login
