# แผน: หน้าวิชาแบบ 2 ปุ่ม + ข้อสอบย่อยรายเรื่อง + สกิล 0–100

## 1. สีพื้นหลังตามชั้น
- หน้า ป.6 พื้นหลังโทนน้ำเงินอ่อน, หน้า ม.3 พื้นหลังโทนส้มอ่อน (แถบเมนูด้านบนก็เปลี่ยนสีตามชั้น)
- สีประจำวิชา (น้ำเงิน/แดง/เขียว/ม่วง) ยังคงเดิมบนการ์ดวิชา

## 2. กดวิชา → 2 ปุ่มใหญ่ ซ้าย/ขวา
```text
[ เรียนรู้จากคลังข้อสอบ ]   [ วิเคราะห์และพัฒนา (ล็อก) ]
  ทำแล้ว 12/40 ข้อ            ปลดล็อกเมื่อทำครบ 40 ข้อ
```
- **เรียนรู้จากคลังข้อสอบ**: ข้อสอบจริงทุกปีรวมกัน ทำต่อเนื่องได้ (นับข้อที่ทำแล้วสะสม) + ยังเลือกทำเต็มชุดรายปีได้
- เมื่อนับครบ 40 ข้อ (ข้อเขียนไม่นับ) ปุ่มขวาปลดล็อก

## 3. วิเคราะห์และพัฒนา
- รายงานรายข้อที่ทำ แบ่งเป็น "โซนความรู้" (สาระ) ชัดเจน เช่น จำนวนและพีชคณิต / การวัดและเรขาคณิต / สถิติ
- แต่ละโซนแสดงเรื่องที่ควรติว (จากผลวิเคราะห์ข้อสอบย้อนหลังที่มีอยู่) พร้อม **สกิล 0–100** ต่อเรื่อง
- สกิลคำนวณจาก: ผลข้อสอบจริงเรื่องนั้น + ผลข้อสอบย่อยเรื่องนั้น (ล่าสุดมีน้ำหนักมากกว่า)
- เรียงเรื่องที่ "ควรศึกษาเพิ่ม" ขึ้นก่อน (ออกบ่อยแต่สกิลต่ำ)

## 4. ข้อสอบย่อยรายเรื่อง (20 ข้อ/เรื่อง)
- ระบบแต่งข้อสอบใหม่ 20 ข้อต่อเรื่อง สไตล์ O-NET ระดับชั้นนั้น โดยใช้ AI แต่งแล้ว **เก็บไว้ในฐานข้อมูล** ให้ทุกคนใช้ชุดเดียวกัน (แต่งครั้งเดียวต่อเรื่อง ไม่เปลืองและคะแนนเทียบกันได้)
- รูปแบบคละ: เลือกตอบ 4 ตัวเลือก, เลือก 2 คำตอบ, เติมคำตอบตัวเลข, ถูก/ผิด, จับคู่ — ตามที่ O-NET ใช้จริง
- ส่งแล้วแสดง **หลอดคะแนน** x/20, เฉลย+คำอธิบายรายข้อ, อัปเดตสกิลของเรื่องนั้นทันที
- ปุ่ม "ไปลุยข้อสอบจริงปีต่างๆ" เมื่อสกิลถึงเกณฑ์

## สิ่งที่ต้องรู้
- ข้อสอบย่อยเป็นข้อที่ระบบแต่งขึ้น ไม่ใช่ข้อสอบทางการ จะติดป้าย "ข้อฝึก (แต่งเพิ่ม)" ให้ชัด
- ครูควรสุ่มตรวจความถูกต้องของเฉลยบางเรื่อง

## Technical details
- `src/styles.css`: เพิ่ม token `--level-p6-bg`, `--level-m3-bg`; LevelPage/SiteNav ใช้ตาม level
- LevelPage: การ์ดวิชาเปลี่ยนเป็น 2 ปุ่ม; ใหม่ route `/bank/$level/$subject` (คลังรวม, นับจาก attempts kind exam/practice ใน progress.ts) และ `/develop/$level/$subject` (ล็อกถ้า < 40)
- ตารางใหม่ `drill_sets(level, subject, topic, items jsonb, created_at)` อ่านได้ทุกคนที่ล็อกอิน; เขียนผ่าน server function เท่านั้น (admin client) 
- server function `getDrillSet` เรียก Lovable AI (structured output, schema ตรวจรูปแบบข้อ) ถ้ายังไม่มีในตาราง; ผลทำบันทึกเป็น attempt kind `drill` ใน progress (sync ขึ้นบัญชีเหมือนเดิม)
- `src/lib/skill.ts`: ฟังก์ชันคำนวณสกิล 0–100 + test กฎ (40 ข้อปลดล็อก, ช่วง 0–100)
