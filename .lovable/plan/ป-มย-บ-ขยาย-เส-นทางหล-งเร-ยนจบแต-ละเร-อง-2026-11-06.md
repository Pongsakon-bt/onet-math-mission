# ปุ่มยุบ/ขยาย + เส้นทางหลังเรียนจบแต่ละเรื่อง

## 1. ปุ่มยุบ/ขยาย
- หน้า "วิเคราะห์และพัฒนา": แต่ละโซน (เช่น จำนวนและพีชคณิต) มีปุ่มลูกศรที่หัวโซน กดเพื่อยุบ/ขยายรายการเรื่อง
- มีปุ่ม "ขยายทั้งหมด / ยุบทั้งหมด" ด้านบน
- เปิดค้างไว้เฉพาะโซนที่มีเรื่อง "ต้องติว" ส่วนโซนที่ผ่านหมดแล้วจะยุบไว้ก่อน
- รายการเรื่องในแดชบอร์ด (สาระใหญ่) ใช้แบบเดียวกัน และมีปุ่มขยาย/ยุบทั้งหมด

## 2. หลังทำข้อสอบย่อยของเรื่องเสร็จ — ทำอะไรต่อ
ใช้เกณฑ์เดิม: ดี ≥ 75, พอใช้ 50–74, ต้องติว < 50

| ผล | สถานะที่เห็น | ทำต่อ |
|---|---|---|
| ต่ำกว่า 50 (ต้องติว) | ป้ายแดง "ยังไม่ผ่าน" | ปุ่ม "ทบทวนเนื้อหา" + "ทำใหม่" (สลับลำดับข้อ/ตัวเลือก) และแสดงข้อที่ผิดพร้อมวิธีคิด |
| 50–74 (พอใช้) | ป้ายเหลือง "เกือบผ่าน" | แนะนำทำซ้ำเพื่อให้ถึง 75 |
| 75–99 (ผ่าน) | ป้ายเขียว "ผ่านแล้ว" ✓ | ปุ่ม "ไปเรื่องถัดไปที่ควรติว" |
| 100 (เชี่ยวชาญ) | ป้ายทอง "เชี่ยวชาญ" | ไปเรื่องถัดไปทันที |

- หน้าผลข้อสอบย่อยจะสรุป: คะแนน, ผ่าน/ไม่ผ่าน, ปุ่มเดินต่อตามตารางด้านบน
- เรื่อง "ถัดไปที่ควรติว" = เรื่องที่สกิลต่ำสุดและออกสอบบ่อยที่สุดในวิชาเดียวกัน
- หัวโซน/สาระแสดงความคืบหน้า เช่น "ผ่าน 3/8 เรื่อง"
- เมื่อผ่านครบทุกเรื่องในวิชา: แสดงการ์ด "พร้อมสอบแล้ว" แนะนำทำ PRE O-NET ครั้งที่ 2 เพื่อวัดผลจริง
- ครูเห็นในหน้ารายคนว่านักเรียนผ่านกี่เรื่อง และเรื่องไหนยังติดอยู่

## รายละเอียดทางเทคนิค
