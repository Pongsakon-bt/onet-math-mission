# แผน: 6 ฟีเจอร์ใหม่ COOL QUIZ : O-NET

ทำทีละรอบ เรียงจากใช้งานบ่อยและเสี่ยงน้อยก่อน

## รอบที่ 1 — โหมดสอบจริง + แจ้งเตือนงาน
**1. โหมดสอบจริง (Mock Exam)**
- หน้าเลือกชุดข้อสอบ/PRE มีปุ่ม 2 แบบ: "ฝึกทำ" (แบบเดิม) และ "สอบจริงจับเวลา"
- จับเวลาถอยหลัง: ป.6 60 นาที, ม.3 90 นาที (ปรับได้ภายหลัง) แสดงเวลาเหลือตลอด เตือนตอนเหลือ 10 และ 1 นาที
- ปิดคำใบ้ ไม่บอกถูก/ผิดระหว่างทำ ยังข้ามข้อและเลือกข้อได้อิสระ
- หมดเวลาส่งให้อัตโนมัติ / กดส่งทีเดียว แล้วจึงเห็นคะแนน เฉลย และวิธีทำ
- ผลสอบบันทึกแยกป้าย "สอบจริง" พร้อมเวลาที่ใช้ ครูเห็นในหน้ารายคน
- เวลาเริ่มเก็บไว้ ถ้ารีเฟรชหน้าเวลายังเดินต่อ ไม่รีเซ็ต

**2. แจ้งเตือนงานที่ครูมอบหมาย**
- เมนู/แดชบอร์ดนักเรียนมีป้ายตัวเลขจำนวนงานที่ยังไม่ทำ
- ป้าย "ใหม่" สำหรับงานที่ยังไม่เคยเปิดดู, "ใกล้ครบกำหนด" (ภายใน 2 วัน) สีส้ม, "เลยกำหนด" สีแดง
- เรียงงานด่วนขึ้นก่อน

## รอบที่ 2 — คาดการณ์คะแนน + เรดาร์ + เกียรติบัตร
**3. คะแนนคาดการณ์ O-NET + กราฟเรดาร์**
- สูตร (โปร่งใส ไม่ใช่ AI): ถ่วงน้ำหนัก PRE ครั้งที่ 2 50%, ข้อสอบย่อยรายสาระ 30%, PRE ครั้งที่ 1 20% (ถ้าไม่มีบางส่วนให้เฉลี่ยจากที่มี) แสดงเป็นช่วงคะแนน เช่น 58–66 พร้อมบอกว่า "เป็นการประมาณ"
- กราฟเรดาร์คะแนนรายสาระของนักเรียน เทียบเส้นค่าเฉลี่ยโรงเรียน
- แสดงในแดชบอร์ดนักเรียน และหน้ารายคนของครู

**4. เกียรติบัตร PDF**
- ได้เมื่อ: ผ่านครบทุกเรื่องในวิชา (100%) หรือ PRE ครั้งที่ 2 ได้ ≥ 80% ("ดีเยี่ยม")
- ใบแนวนอน A4 มีโลโก้ ชื่อนักเรียน โรงเรียน วิชา ระดับชั้น เหตุผลที่ได้ วันที่ พิมพ์/บันทึก PDF ได้
- ปุ่ม "รับเกียรติบัตร" ปรากฏในแดชบอร์ดเมื่อถึงเกณฑ์ ครูพิมพ์ให้นักเรียนได้

## รอบที่ 3 — ฟีเจอร์ที่ใช้ AI (ใช้เครดิต)
**5. AI ช่วยตรวจอัตนัยภาษาไทย**
- เมื่อนักเรียนส่งคำตอบเขียน ระบบให้ AI ร่างคะแนนตามรูบริก (เนื้อหา, การเรียบเรียง, ภาษา) พร้อมความเห็น
- ครูเห็น "คะแนนที่ AI แนะนำ" แล้วกดอนุมัติหรือแก้คะแนน คะแนนจริงมาจากครูเท่านั้น นักเรียนเห็นหลังครูอนุมัติ
- ใช้เครดิตประมาณเล็กน้อยต่อคำตอบ

**6. เสียงอ่านภาษาอังกฤษ**
- ปุ่มลำโพงที่บทสนทนา/บทอ่านและโจทย์ภาษาอังกฤษ
- เริ่มด้วยเสียงอ่านในเครื่อง (ฟรี ไม่เสียเครดิต) ปรับความเร็วช้า/ปกติได้ หากต้องการเสียงคุณภาพสูงค่อยเปลี่ยนเป็น AI ภายหลัง

## รายละเอียดทางเทคนิค
- Mock: เพิ่ม prop `mode: "practice" | "mock"` ใน ExamRunner; เก็บ `started_at`/`duration` ใน localStorage + คอลัมน์ `mode`, `duration_sec` ใน `attempts` (เพิ่มแบบ nullable)
- Alerts: ตาราง `assignment_views` (student_id, assignment_id, seen_at) + RLS เจ้าของ; กฎ ใหม่/ใกล้กำหนด/เลยกำหนด ใน src/lib/assignments.ts พร้อม test
- Prediction: ฟังก์ชันใน src/lib/prediction.ts (มี test สำหรับน้ำหนักและกรณีข้อมูลไม่ครบ); ค่าเฉลี่ยโรงเรียนผ่าน server function ที่ RLS scope ด้วย `teacher_school()`/โรงเรียนของนักเรียน (คืนเฉพาะค่าเฉลี่ย); เรดาร์ใช้ recharts
- Certificate: route `/certificate/$level/$subject` ใต้ _authenticated, print CSS แบบ print-report; เกณฑ์ใน src/lib/skill.ts (+test)
- Essay AI: server function ใช้ Lovable AI Gateway เขียนลงคอลัมน์ `ai_score`, `ai_feedback` ใน `essay_answers` (column grant ให้เฉพาะ service ฝั่ง server); ครูอนุมัติคัดลอกไปที่ score
- TTS: Web Speech API (`en-US`) ไม่มี backend

## ยืนยันก่อนเริ่ม
- เวลาสอบจริง 60/90 นาที, เกณฑ์ "ดีเยี่ยม" 80%, และน้ำหนักสูตรคาดการณ์ — ปรับได้ถ้าต้องการค่าอื่น
