# เชื่อมนักเรียน–ครู–โรงเรียนให้ครบ

## สิ่งที่มีอยู่แล้ว
- นักเรียนและครูสมัครด้วยรหัสโรงเรียน 10 หลัก ระบบตรวจกับรายชื่อ สพฐ.
- ครูคนแรกของโรงเรียน "เปิดโรงเรียน" ในระบบ
- ครูเห็นผลสอบ ข้อเขียน และรีเซ็ตรหัสนักเรียนได้เฉพาะโรงเรียนตัวเอง
- ผู้ดูแลระบบเห็นทุกโรงเรียน

## รอยต่อที่ยังขาด (เรียงตามความสำคัญ)
1. **ใครก็สมัครเป็นครูได้** — ใส่รหัสโรงเรียนใดก็ได้แล้วจะเห็นข้อมูลนักเรียนทั้งโรงเรียนทันที ไม่มีการยืนยันตัวครู
   - แก้: ครูคนแรกของโรงเรียนได้ "รหัสเชิญครู" ครูคนถัดไปต้องใช้รหัสนี้ หรือให้ผู้ดูแลระบบอนุมัติ (สถานะ "รออนุมัติ" จนกว่าจะอนุมัติ)
2. **นักเรียนไม่มีชั้น/ห้อง** — ครูแยกดูห้อง ป.6/1, ม.3/2 ไม่ได้ เห็นนักเรียนทั้งโรงเรียนปนกัน
   - แก้: เพิ่มชั้น (ป.6/ม.3) และห้องตอนสมัคร พร้อมตัวกรองห้องในหน้าครูและรายงาน PDF
3. **ครูไม่ผูกกับห้องหรือวิชาที่สอน** — ครูทุกคนเห็นทุกห้อง
   - แก้: ครูเลือกห้อง/วิชาที่ดูแล หน้าครูเปิดที่ห้องของตัวเองก่อน (ยังดูทั้งโรงเรียนได้)
4. **ไม่มีหน้า "โรงเรียน" ภาพรวม** — ไม่มีหน้ารวมรายชื่อครู จำนวนนักเรียน และความคืบหน้าของทั้งโรงเรียน
   - แก้: เพิ่มแท็บภาพรวมโรงเรียนในหน้าครู (รายชื่อครู, จำนวนนักเรียนต่อห้อง, % ที่ทำ PRE O-NET ครั้งที่ 1 แล้ว)
5. **ครูมอบหมายงานไม่ได้** — ครูสั่งให้ห้องทำชุดสอบหรือเรื่องย่อยไม่ได้ นักเรียนไม่เห็นงานที่ครูสั่ง
   - แก้: ครูมอบหมายชุด/เรื่องให้ห้อง พร้อมกำหนดส่ง นักเรียนเห็นใน "แดชบอร์ดของฉัน" ครูเห็นว่าใครทำแล้ว/ยังไม่ทำ
6. **นักเรียนย้ายหรือสมัครผิดโรงเรียนแก้ไม่ได้** และครูลบ/ปิดบัญชีนักเรียนที่ออกไปแล้วไม่ได้
   - แก้: ครูย้ายห้อง/ปิดบัญชีนักเรียนในโรงเรียนตัวเอง; การย้ายโรงเรียนให้ผู้ดูแลระบบทำ
7. **หน้าครูยังไม่อยู่ในประตูต้องเข้าสู่ระบบ** แบบเดียวกับหน้าสอบ (ตอนนี้ตรวจในหน้าเอง) — ย้ายให้สอดคล้องกัน

## ขอบเขตที่จะทำ
- ทำข้อ 2–7 ทั้งหมด
- ไม่ทำข้อ 1 (การยืนยันตัวครู) ตามที่ผู้ใช้เลือก — ครูยังสมัครด้วยรหัสโรงเรียนได้เหมือนเดิม

## รายละเอียดทางเทคนิค
- `profiles` เพิ่ม `grade` (p6/m3) และ `room`; `registerAccount` รับค่าเพิ่ม; บัญชีเดิมให้ครูกำหนดห้องภายหลัง
- ตาราง `teacher_classes` (teacher_id, grade, room, subject) และ `assignments` / ใช้ `attempts` เดิมตรวจการส่ง
- ย้าย `teacher.tsx` และ `teacher_.$studentId.tsx` ไปใต้ `_authenticated` โดยคง URL เดิม
- ครูย้ายห้อง/ปิดบัญชีนักเรียนผ่าน server function ที่ตรวจว่าอยู่โรงเรียนเดียวกัน; ผู้ดูแลระบบย้ายโรงเรียนผ่าน admin.functions
- เพิ่มเทสต์: ตัวกรองห้อง, สถานะงานที่มอบหมาย (ทำแล้ว/ยังไม่ทำ/เลยกำหนด)
