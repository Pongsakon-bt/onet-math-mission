# จัดหน้าแดชบอร์ดใหม่

## 1. สีตามวิชาที่เลือก
- กดวิชาไหน ส่วน "รายละเอียดรายวิชา" ทั้งหมดเปลี่ยนเป็นสีของวิชานั้น: คณิตน้ำเงิน ไทยแดง อังกฤษเขียว วิทย์ม่วง
- มีแถบหัววิชาสีเต็ม (ไอคอน + ชื่อวิชา + ชั้น) และพื้นหลังส่วนนั้นเป็นสีวิชาแบบอ่อน ๆ
- ปุ่มเลือกวิชาเปลี่ยนเป็นปุ่มใหญ่ 4 ปุ่มมีไอคอนและสีของแต่ละวิชา ปุ่มที่เลือกจะเป็นสีเต็ม
- ปุ่ม ป.6/ม.3 และส่วนภาพรวมด้านบนคงเป็นสีน้ำเงินกลางของเว็บเหมือนเดิม

## 2. แยกเป็น 2 ปุ่ม (แท็บ) ใต้หัววิชา
```text
[ แหล่งเรียนรู้ ]   [ ฝึกทำข้อสอบ ]
```
- **แหล่งเรียนรู้** (แทน "เรื่องที่ควรเรียนต่อ"): รายการสาระพร้อมระดับ ดี/พอใช้/ต้องติว และปุ่ม "เรียนรู้" ไปหน้าสรุปเนื้อหา เรียงจากเรื่องที่อ่อนที่สุดก่อน การ์ดออกแบบให้วันหลังเพิ่มวิดีโอ เอกสาร หรือลิงก์ได้
- **ฝึกทำข้อสอบ** (แทน "เรื่องที่ต้องติวทั้งหมด"): สาระและเรื่องย่อยแบบยุบ/ขยายเหมือนเดิม พร้อมปุ่มทำข้อสอบย่อย และปุ่มลัดไป PRE O-NET / ข้อสอบรายปี
- ระบบจำแท็บที่เลือกไว้ใน URL กดย้อนกลับแล้วยังอยู่แท็บเดิม

## 3. ลำดับการแสดง (บนลงล่าง)
```text
1. หัวหน้า + ป.6/ม.3                       เล็ก
2. ภาพรวม 4 วิชา + วิเคราะห์ภาพรวม          ใหญ่ (เห็นทันที)
3. ปุ่มเลือกวิชา 4 ปุ่ม                      กลาง เด่นด้วยสีวิชา
4. แถบหัววิชาสีเต็ม + คะแนนคาดการณ์ O-NET    ใหญ่ (ภาพสรุปของวิชา)
5. แท็บ  แหล่งเรียนรู้ | ฝึกทำข้อสอบ          ใหญ่ (สิ่งที่ต้องทำต่อ)
6. กราฟความรู้แต่ละสาระ + พัฒนาการ           กลาง วางคู่กันบนจอกว้าง
7. ข้อเขียนที่ส่งให้ครูตรวจ                    เล็ก
8. ประวัติการทำ                               เล็ก ยุบไว้ก่อน กดดูได้
```
เหตุผล: ข้อมูลที่ช่วยตัดสินใจว่าจะทำอะไรต่อ (คะแนนคาดการณ์ เรียน ฝึก) อยู่บน ส่วนกราฟและประวัติเป็นข้อมูลอ้างอิง จึงอยู่ล่างและเล็กลง
