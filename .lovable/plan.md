# แผน: วัดพื้นฐาน → เรียนรายเรื่อง → สอบซ้ำ → แดชบอร์ด

ตอนนี้ยังไม่มีระบบบัญชีผู้ใช้ ผลทั้งหมดจะเก็บไว้ในเครื่องของนักเรียนก่อน เมื่อทำระบบโรงเรียนแล้วจึงย้ายข้อมูลขึ้นไปให้ครูเห็น

## ภาพรวมการใช้งาน
```text
เลือกชั้น -> เลือกวิชา -> [วัดพื้นฐาน] -> แดชบอร์ดของฉัน
                                   |-> เรื่องที่อ่อน -> เรียนรู้ (สรุป + ฝึกข้อเก่า)
                                   |-> สอบซ้ำเฉพาะเรื่อง / วัดพื้นฐานรอบใหม่
                                   '-> แดชบอร์ดแสดงพัฒนาการก่อน-หลัง
```

## 1. แบบวัดความรู้พื้นฐาน
- ปุ่ม "วัดความรู้พื้นฐาน" ในแต่ละวิชา (ป.6 / ม.3)
- สุ่มจากข้อสอบปี 2565–2568 ให้ครบทุกสาระ สาระละประมาณ 4 ข้อ (รวมราว 16–20 ข้อ)
- ข้อเขียนซึ่งต้องให้ครูตรวจจะไม่ถูกสุ่มมาใช้
- ใช้หน้าทำข้อสอบเดิม (แถบเลขข้อ คำใบ้ จับเวลา)
- ส่งแล้วแสดงผลทันที: แต่ละสาระได้กี่เปอร์เซ็นต์ และระดับ อ่อน / พอใช้ / ดี

## 2. หน้าเรียนรู้รายเรื่อง
แต่ละสาระมี 2 ส่วน:
- **สรุปความรู้:** ผมเขียนสรุปสั้น ๆ พร้อมตัวอย่างโจทย์ (เป็นเนื้อหาที่ผมแต่งเอง ครูควรช่วยตรวจ)
- **ฝึกทำ:** รวมข้อสอบเก่าทุกปีในสาระนั้น ทำทีละข้อ มีคำใบ้ ส่งแล้วเห็นวิธีทำ

เริ่มจากคณิต ป.6 และ ม.3 ก่อน แล้วจึงทำวิชาอื่น เพราะสรุปความรู้มีหลายเรื่อง

## 3. สอบซ้ำ
- สอบซ้ำเฉพาะสาระที่เรียนแล้ว โดยสุ่มข้อที่ยังไม่เคยเจอก่อน
- หรือวัดพื้นฐานรอบใหม่ทั้งวิชา

## 4. แดชบอร์ดของฉัน
- คะแนนแต่ละสาระ (ครั้งแรกเทียบกับครั้งล่าสุด)
- กราฟพัฒนาการตามครั้งที่ทำ
- เรื่องที่ควรเรียนต่อ เรียงจากเรื่องที่อ่อนที่สุด
- สถานะของแต่ละสาระ: เรียนแล้ว / ฝึกแล้วกี่ข้อ / ถูกกี่เปอร์เซ็นต์
- รวมผลข้อสอบเต็มชุดที่เคยทำด้วย

## ทำทีหลัง
- บัญชีโรงเรียนและนักเรียน (รหัสโรงเรียน) ย้ายผลขึ้นระบบให้ครูเห็นทั้งห้อง

## รายละเอียดทางเทคนิค
- เก็บผลแต่ละครั้งไว้ใน localStorage ในรูปแบบ `{ kind: diagnostic|practice|retest|full, level, subject, at, items: [{ qid, strand, topic, correct, points }] }` เพื่อย้ายขึ้นฐานข้อมูลได้ตรง ๆ ภายหลัง
- เอาข้อสอบจากทุกชุดมารวมกันโดยใช้ `strandOf()` ที่มีอยู่ ใส่ id เดิมของข้อ แล้วเก็บรูปของแต่ละข้อไว้
- ทำ ExamRunner ให้รับชุดข้อที่สร้างขึ้นเองได้ (ชุดชั่วคราวที่ไม่มีปี) และแยกที่เก็บคำตอบด้วย storageKey
- เส้นทางหน้าใหม่: `/diagnostic/$level/$subject`, `/learn/$level/$subject/$strand`, `/dashboard`
- สรุปความรู้เก็บใน `src/data/lessons/<level>-<subject>.ts`
- เพิ่มลิงก์ "แดชบอร์ดของฉัน" ในหน้าแรก
- ใช้กราฟจาก recharts (มีในโปรเจกต์อยู่แล้วผ่านชุดกราฟของ shadcn)
